# 小吴乐意 · 生酮与身体重塑实证记录 🌿

这是一个用于记录、追踪和可视化个人生酮饮食（Ketogenic Diet）历程及身体指标变化的轻量级静态网站。

## 🎯 初衷

数据是身体最诚实的反馈。本项目旨在通过长期、连续地记录体重、体脂率以及定期的医疗化验指标（如血酮、空腹胰岛素、血脂等），客观呈现生酮饮食对身体的真实影响。既是个人健康管理的仪表盘，也希望能为更多对生酮饮食感兴趣的朋友提供一份真实的实证参考。

## ✨ 特性

- **极简现代 UI**：基于 Tailwind CSS 构建，优雅的玻璃拟物化（Glassmorphism）卡片设计。
- **直观数据可视化**：集成 ECharts，动态生成体重与体脂双轴趋势图，变化一目了然。
- **灵活的医疗时间轴**：不仅能记录日常数据，还能通过模块化卡片完美适配任何不规则的医疗化验单和个人碎碎念日记。
- **绝对的隐私与掌控**：纯前端静态单文件架构，数据以 JSON 格式存储于代码中，随 GitHub 托管，无第三方数据库隐私泄露风险。

## 🚀 部署与运行

本项目采用纯静态架构，无需任何复杂的后端环境。

1. **本地预览**：克隆本仓库，直接在浏览器中打开 `index.html` 即可。
2. **线上访问**：已接入 Cloudflare Pages，通过 GitHub 提交代码后，页面会自动完成全球 CDN 部署与更新。

## 📝 如何添加数据？

所有的记录都保存在 `index.html` 底部的 `journalData` 数组中。只需按照以下 JSON 格式追加数据并推送到 GitHub 即可自动更新网站：

```javascript
{
    date: 'YYYY-MM-DD',
    type: 'daily', // daily(日常) | medical(医疗) | milestone(里程碑)
    badge: '📝 日常打卡',
    weight: 148.0, 
    fat: 24.2,
    diary: '今天的身体感受与总结...',
    // 医疗记录可附加 medicalData 字段
}
